Security & Responsible Use

Sentinel Scope is distributed for defensive, research and educational use. It intentionally avoids embedding exploit code or automating attacks. The maintainers expect users to:

- Only run scans (especially non-simulated checks) on systems for which they have explicit, written authorization.
- Follow applicable laws and corporate policies.
- Report security issues to maintainers responsibly.

If you discover behavior that could be used maliciously, please open an issue or contact the maintainers.
